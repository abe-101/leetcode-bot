# Privacy Policy

Last updated: February 11, 2025

## Introduction
This Privacy Policy describes how the Leetcode Bot ("we", "us", or "our") collects, uses, and handles your information when you use our Discord bot service.

## Information We Collect
### Automatically Collected Information
- Discord User ID
- Discord Server ID
- Command usage data
- Leetcode problem numbers and programming languages requested

### We DO NOT Collect
- Personal messages
- Direct message content
- User profile information
- Any information outside of bot interactions

## How We Use Information
We use the collected information for:
- Providing leetcode solutions
- Tracking command usage for service improvements
- Generating anonymous usage statistics
- Debugging and error monitoring

## Data Storage
- All data is stored temporarily in memory and log files
- Command usage statistics are reset daily
- We do not maintain any permanent user databases
- Log files are automatically rotated and old logs are deleted

## Data Sharing
We do not share any user data with third parties. The only data visible to other users are:
- Public command interactions in Discord channels
- Solutions to leetcode problems (which are publicly available)

## Security
We implement appropriate security measures to protect the limited data we collect:
- Secure bot token storage
- Regular security updates
- Limited access to log files

## User Rights
You have the right to:
- Use the bot privately through ephemeral messages
- Request deletion of your data (though we store minimal data)
- Opt out of using the bot at any time

## Changes to This Policy
We may update this Privacy Policy from time to time. We will notify users of any material changes by posting the new Privacy Policy in our GitHub repository.

## Contact
If you have any questions about this Privacy Policy, please contact us:
